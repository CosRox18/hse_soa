Модели и хэндлеры из `openapi/marketplace.yaml` генерируем через datamodel-code-generator. Генерация запускается при сборке, результат в `app/generated`.

На запрос открываем транзакцию, фиксируем её до отправки ответа. created_at задаётся в БД, updated_at меняется триггером, на status товара есть индекс. При работе с заказом блокируем пользователя, потом товары в порядке ID и промокод. Это не даёт параллельным запросам потратить один остаток или последнее использование промокода дважды. Два активных заказа одного пользователя дополнительно запрещены уникальным индексом. При обновлении оставляем место под возврат всех активных резервов.

В позициях заказа сохраняем снимки цен. При изменении состава возвращаем старые остатки и резервируем новые, цены берём заново. Всё делаем в одной транзакции, при ошибке сохранятся старые позиции и остатки. В user_operations записываем только успешные операции.

Для промокода при обновлении учитываем уже занятое этим заказом использование. Если сумма стала ниже минимума, снимаем промокод и возвращаем использование. Если код истёк или отключён, откатываем обновление. При отмене возвращаем товары и использование промокода, повторную отмену отсекаем по состоянию заказа.

Деньги считаем в рублях через Decimal, скидку округляем до копеек через ROUND_HALF_UP. Повтор одного product_id в позициях запрещаем.

При регистрации выдаём USER, SELLER и ADMIN создаём через CLI. В JWT кладём роль и тип токена, при каждом запросе сверяем роль с БД. Access действует 20 минут, refresh — 14 дней. После смены роли старые токены не подходят. Владельца товара и заказа проверяем отдельно от роли. В JSON-лог пишем UUID запроса и тело изменений, пароли и токены маскируем. UUID возвращаем в X-Request-Id.

configure.py запускаем только при первом запуске:

```sh
python3 scripts/configure.py
docker compose up --build -d --wait
docker compose logs migrate api
```

Swagger: <http://127.0.0.1:18082/docs>. Создание продавца и администратора:

```sh
docker compose exec api python scripts/manage.py seller --role SELLER
docker compose exec api python scripts/manage.py admin --role ADMIN
```

demo.py выполняет HTTP-запросы и выводит SELECT из бизнес-таблиц.

```sh
docker compose exec api python scripts/demo.py
docker compose exec db psql -U marketplace -d marketplace
```
